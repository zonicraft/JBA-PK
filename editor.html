JBA PK Editor

Click Open game folder… and choose the game folder (the one that contains index.html and this editor), then allow editing when the browser asks.

Pick a map on the left. You'll see the real tiles and character sprites. Click an event to edit it; its movement paths are drawn on the map. Click an empty tile and use Add event here to make a new one. Press Ctrl+S to save. A backup of each map is stored in _editor_backups the first time you save it each day.

Works in Chrome and Edge.
