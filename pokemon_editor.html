JBA Pokémon Editor

Click Open game folder… and choose the game folder (the one with index.html and pokemon.json), then allow editing.

Where the Pokémon come from: pokemon.json is the master. Saving writes it and also regenerates data/pokemon.js, which the game loads (so it works when opened from disk). A backup is kept in _editor_backups the first time you save each day.

Works in Chrome and Edge.
